# Building releases

*(Português: [docs/pt/RELEASING.md](pt/RELEASING.md))*

The project uses [electron-builder](https://www.electron.build/). The configuration is in the `build` field of `package.json`.

## What gets built

| System | Files | Architectures |
|---|---|---|
| **Ubuntu / Debian** | `.deb` | x64 |
| **Fedora / openSUSE** | `.rpm` | x64 |
| Linux (any) | `.AppImage`, `.tar.gz` | x64 |
| **Windows** | `.exe` installer (NSIS) and portable `.exe` | **64-bit (x64) and 32-bit (ia32)** |
| **macOS** | `.dmg` and `.zip` | Intel (x64) and Apple Silicon (arm64) |

Electron no longer ships 32-bit Linux.

## Option 1 — Everything at once on GitHub (recommended)

1. Bump the version in `package.json` and update `CHANGELOG.md`.
2. Commit and create the tag:
   ```bash
   git tag v0.1.0
   git push origin main --tags
   ```
3. The **Release** workflow (`.github/workflows/release.yml`) builds on Linux, Windows and macOS and publishes a **GitHub Release** with every installer and `SHA256SUMS.txt`.

You can also run it by hand in *Actions → Release → Run workflow* (produces the files as artifacts, without publishing).

## Option 2 — On your own machine

```bash
npm install
npm run release          # whatever your system can build
npm run release:linux    # .deb .rpm .AppImage .tar.gz
npm run release:win      # Windows 64 and 32-bit
npm run release:mac      # .dmg and .zip (on a Mac only)
npm run release:all      # tries all three
```

Files land in `dist/` with `SHA256SUMS.txt`. The script checks the prerequisites and explains what is missing:

| Build… | …on | Needs |
|---|---|---|
| Linux | Linux | `rpmbuild` (`sudo apt install rpm` or `sudo dnf install rpm-build`) |
| Windows | Windows | nothing |
| Windows | Linux/macOS | Wine (`sudo apt install wine64`) — or use GitHub Actions |
| macOS | macOS | nothing |
| macOS | Linux/Windows | **not possible** — use a Mac or GitHub Actions |
| Linux | Windows | use WSL (Ubuntu) or GitHub Actions |

Quick test without installers: `npm run release -- --dir` (only packs into `dist/<system>-unpacked`).

## Code signing

The installers come out **unsigned** (the project has no certificate). What that means for people downloading:

- **Windows:** SmartScreen warns "unrecognized app" → *More info → Run anyway*.
- **macOS:** Gatekeeper blocks it. Right-click → *Open*, or run `xattr -cr "/Applications/Llamafile Brain.app"`.

To sign, configure the certificate secrets in the repository and remove `CSC_IDENTITY_AUTO_DISCOVERY: 'false'` from the workflow (see the [electron-builder docs](https://www.electron.build/code-signing)).

## Icons

`assets/icon.svg` is the source. `npm run icons` regenerates `build/icon.png` and `build/icon.ico` (needs `rsvg-convert` and ImageMagick). The macOS `.icns` is generated by electron-builder from the PNG.

## Release checklist

- [ ] `npm test` and `npm run e2e` pass
- [ ] `CHANGELOG.md` and version updated
- [ ] Tag `vX.Y.Z` pushed
- [ ] Release published with the 5 installer types and `SHA256SUMS.txt`
- [ ] Installed and opened on at least one system of each family
